Paleta de colores

Esta paleta se usa como base visual para todo el sistema. La interfaz debe sentirse limpia, ordenada y fácil de leer, usando el azul oscuro como identidad principal y los tonos suaves como apoyo visual.

Azul claro
#5AA6DF
Azul medio
#3F82A3
Azul oscuro
#17385F
Gris
#A6A6A6
Verde grisáceo
#A6C0BB
Regla visual: usar los mismos colores en todas las pantallas. No crear un color nuevo por cada caso de uso. Los estados activo, inactivo, error y advertencia deben verse consistentes en todo el sistema.

Organización de módulos en la interfaz

En el documento se mantienen los nombres formales de los módulos. En la interfaz se usan nombres más cortos para que el menú sea claro y no se vea sobrecargado.
